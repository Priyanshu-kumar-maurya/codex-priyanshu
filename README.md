## 💻 Interactive Developer CLI Simulator

The portfolio features a built-in interactive terminal emulator. Visitors can type commands or click quick-action pills:

```bash
guest@codex:~$ help
Available Commands:
  - about       : Learn more about Priyanshu & his background
  - repos       : List real GitHub repositories & projects (29 Total)
  - projects    : View featured web projects with live URLs
  - stats       : Live GitHub profile metrics & project stats
  - skills      : Print technical skill competencies (MERN, SQL, C++)
  - location    : Current city & residency details (Mumbai, IN)
  - education   : Display academic details (BCA Scholar)
  - contact     : Get email, location, and contact coordinates
  - socials     : Direct links to LinkedIn, GitHub, Instagram, Bio
  - theme       : Toggle dark and light mode
  - clear       : Clear terminal window (Ctrl+L)
  - sudo hire   : Unlock full developer privileges
  - date        : Current date and time
```

## 🚀 Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Priyanshu-kumar-maurya/codex-priyanshu.git
cd codex-priyanshu
```

### 2. Launch in Browser
No compilation, bundling, or node dependencies are required. Open `index.html` directly in any web browser:

```bash
# On Windows PowerShell
Start-Process index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```
